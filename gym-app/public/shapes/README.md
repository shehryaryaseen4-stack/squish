# Body type photos

Members pick "my body now" and "the body I want" from pictures. Without photos
the app draws them. To use real photos for every gym, put them here and list
them in `index.json`:

```json
{ "male-now-belly": "male-now-belly.jpg", "female-want-toned": "female-want-toned.jpg" }
```

Names are `<male|female>-<now|want>-<look>`:

- now: skinny, slim, average, belly, heavy, bulky
- want, men: healthy, slim, toned, athletic, muscular, bodybuilder
- want, women: healthy, slim, toned, curvy, athletic, fitness

Use tall photos (about 3:5, e.g. 480×800), front view, plain background, the
same style for all. Only use photos you own or have a licence for (stock photo
licence, your own shoot, or AI images you are allowed to sell), with the
models' permission. A gym can also replace any picture from
Settings → Body type photos.
